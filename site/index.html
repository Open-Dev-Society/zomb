zomb

v0.0.1 · MIT

Your agent writes code fast. zomb checks what it left behind: the security holes, the files nothing uses any more, three libraries doing one job, and the shortcuts it took to make your tests pass.

$ npx zomb

JavaScript and TypeScriptno account, no API keyyour code never leaves your machine

One command, one report

It reads your repo the way a careful reviewer would, then tells you what to delete first.

What it checks

Security

  • API keys pasted into code, shown masked
  • committed .env files
  • secrets shipped to the browser in NEXT_PUBLIC_*
  • routes that write to your database with no auth check
  • SQL and shell built from strings, eval, raw HTML
  • vulnerable production packages

Zombie code

  • files nothing imports or names
  • files only their own tests keep alive
  • unused packages and dead exports
  • pages and API routes nothing links to

Sprawl

  • lines added against lines deleted, month by month
  • three icon sets, two date libraries
  • LandingV2 next to Landing
  • copy-pasted blocks and helpers defined twice

Architecture

  • import cycles
  • files past 500 lines
  • shared code scattered across utils/, lib/, helpers/
  • deep ../../../ imports and mixed file naming

Guard

It also stops the mess while the agent is still writing it.

Install the Claude Code plugin and zomb checks every edit before it lands, in about 50 ms. It reads only the lines being added, so removing a suppression is never punished.

Blueprint

The rules your codebase already follows, written down once and held to.

zomb blueprint reads the code and proposes only the rules it mostly follows already, each with its evidence. You approve them once; Guard then holds every agent to them, and the pull request check holds every change.

On every pull request

A check that fails on what this change broke, not on debt you inherited.

zomb --save-baseline accepts today's findings, so only new ones can fail a build. Add the GitHub Action, or install the app and skip the workflow file.

Fix

Deleting is the only part a build can prove, so that is the part zomb does itself.

zomb fix works on a new branch. It runs your typecheck, lint, tests and build first and keeps the ones that pass as its gates, then deletes in small batches and re-runs them after each one. A batch that breaks a check is undone and retried item by item, so anything that turns out to be needed is reported, not removed. No AI, no API key.

Install

Three ways in, all free.

$ npx zomb
$ claude plugin install zomb@zomb
$ npx zomb blueprint --write

The CLI, the plugin, the GitHub Action and the self-hosted server are MIT and stay free. The hosted version adds trends across repos and a weekly clean-up issue handed to the agent your team already pays for.
